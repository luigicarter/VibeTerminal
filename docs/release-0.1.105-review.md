# Release 0.1.105 audit

September 9, 2026. This release integrates the previously uncommitted recovery,
observed-stop, Codex hook-trust and board-drag work, then adds the fixes below.
Earlier evidence remains in [orchestrator-recovery-review.md](orchestrator-recovery-review.md).

## Issues reproduced and repaired

- **Pending input hid Codex work.** Escape then Enter displayed Awaiting activity
  despite fresh identified work. Separate pending-turn evidence now drives
  Working or Needs input across the pane, sidebar, directory and dashboard.
  Input ownership and raw result evidence remain pending. Delayed/duplicate
  callbacks, ended tools/turns, changed roots and restarted processes cannot
  manufacture new work. Tool return retains observed thinking time; old-turn
  completion retires the display without completing the later submission.
- **Restart creation could lose its PID.** A native creation event can precede
  the renderer's new launch token. The directory's paused fallback rejected that
  event. Incoming native events now check the authoritative runtime generation,
  preserving the replacement PID and rejecting old callbacks. Real Electron
  acceptance now verifies one replacement process and launcher invocation.
- **Failed/concurrent restarts could create unintended replacements.** Restart
  ignored false stop results and could increment a replacement's token after an
  asynchronous stop returned. Failed/rejected stops now report an error, and the
  state update only changes the original token. Concurrent requests cannot
  increment it twice.
- **Release gates omitted regressions.** Gates now include all frontend tests,
  Codex trust and pending-activity tests, source closure/process acceptance, and
  frame-level drag/resize acceptance. CI also checks packaged process closure.
- **The hidden navigation fixture intermittently stalled.** Renderer CDP and the
  browser debugging endpoint became unresponsive. The fixture now declares hidden
  screenshot mode and disables native occlusion/background behavior. Two successive
  stress runs each passed 30 navigation transitions. Optional diagnostics remain.
  This does not establish a corresponding visible-window production failure.

## Boundaries

Hidden compositor screenshots were unavailable; packaged checks use application
inventory, DOM state, PTYs and process observations. No new cloud-model task
against a user's repository or physical microphone recording was performed.
Vite retains its existing bundle-size advisory. Supervised-process proof and
model interpretation retain the recovery review's limits. Publication does not
restart active workspaces; users apply the update through Update/Restart.
