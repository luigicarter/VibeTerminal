# Live updates in Workspace History

- Workspace tools / History now refreshes the open chat automatically as the
  provider saves messages, without reopening it or clicking Latest each time.
- New messages follow at the bottom. Scrolling up or reading older history keeps
  your position and shows a Conversation updated button; Latest resumes following.
- Refresh preserves loaded content while fetching, replaces edited messages
  without duplication, and ignores late results after switching or closing chats.

History refresh reads local saved conversations; it does not make model requests
or enable the microphone. Providers that save only completed messages will show
them when saved, rather than token by token.

This update also includes the spoken-response fixes from v0.1.88. Use Check for
update, then Update and Restart to install.
