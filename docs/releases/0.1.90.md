# Hey Vibe hears the whole command

- After "Hey Vibe", the recording no longer closes before you start talking. The
  wake phrase's own trailing silence used to count against the end-of-speech
  budget, which cut most commands off and answered with "I didn't catch that."
- Spoken replies survive small differences in how the speech provider labels its
  audio, so a missing sample-rate header no longer turns a reply into the
  fallback voice.
- Brain models with mandatory reasoning get a reply budget that scales with their
  context window and a low reasoning effort, with a one-time retry if the
  provider rejects the setting or the model still runs out of room. Failures now
  say which stage failed instead of a generic upstream message.
- A wake-detector failure leaves the Orchestrator, microphone and Talk now
  running instead of switching everything off; a stuck audio window is rebuilt
  on retry; a malformed saved preferences list no longer breaks the Settings
  panel.

The fallback alert phrases are still the offline Windows voice, so a failed turn
still sounds different from a successful one. Real-microphone behavior and the
live speech provider were not exercised by the automated checks; this release is
meant to be verified with a real voice turn. Details and remaining follow-ups are
in `docs/orchestrator-voice-deep-dive.md`.

Use Check for update, then Update and Restart to install.
