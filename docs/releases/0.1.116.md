Lina Terminal 0.1.116 adds more ways to run models and keeps terminal conversations connected to the correct saved chat.

- Configure models once for Open Claude Code and the separately bundled Open Codex CLI.
- Run Codex Web in the native terminal with browser sign-in, account model selection, image attachments, and colored diffs.
- Resume the latest selected chat after clearing or switching conversations, including hidden panes.
- Use refreshed Fusion/Open Fusion command menus and inspect local Git branches and worktrees.
- Improve Orchestrator task assignment, observation, and terminal resource cleanup.
- Keep an Open Codex pane connected when a nested CLI exits.
- Prevent a terminal resize/redraw error from freezing the workspace.

Existing settings and workspaces remain in the same application profile. Applying the update uses the normal Update/Restart controls.
