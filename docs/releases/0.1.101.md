# vibeTerminal 0.1.101

- Watch an existing terminal for readiness or task completion, with request-linked progress and result reports.
- Receive summaries of observed agent results while other work continues. Readiness alone never verifies accomplishments or supplies missing results to dependent tasks.
- Send follow-up prompts to busy agents with clearer delivery status and stronger protections against duplicate or uncertain input.
- Start terminals in background projects and hidden panes; switching views attaches to the existing process.
- Stream spoken replies sooner and recover from stalled microphone capture or local voice helpers.
- Preserve conversation context across voice follow-ups and interruptions.
- Keep coding agents alive during input editing, retain blocked work for recovery, and report unverified work when an agent exits.
- Fix readiness watches that could remain stuck after overlapping Fusion or Open Fusion input.

Updates remain user-controlled: choose **Check for update**, then **Update** and **Restart** when ready.
