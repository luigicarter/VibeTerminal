Orchestrator task assignment now distinguishes new work from continuing an existing conversation.

- Independent tasks default to a new agent conversation. Asking for a provider in a project, such as “a Codex terminal,” no longer selects an unrelated existing pane.
- Related follow-ups can continue with their task's owner. Explicitly selected terminals and existing-terminal groups remain supported.
- Existing-conversation input requires selection evidence before dispatch. An inconclusive review stops without sending input or moving the task to another agent.

This update addresses incorrect recipient selection. Separate model-formatting and terminal-operation completion-reporting limitations remain; it does not replay previously submitted requests.

Install through **Check for update → Update → Restart**. Running workspaces are not restarted automatically.
