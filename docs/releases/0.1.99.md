# Orchestrator terminal operator

The Orchestrator now carries out terminal tasks through an observe-act-verify loop. It can work through menus and questions across multiple steps instead of stopping after a canned acknowledgment.

- Send tasks to fresh terminals without requiring a manually submitted first prompt.
- Navigate with keyboard shortcuts, function keys, multiline paste and mouse controls where the terminal application supports SGR mouse reporting.
- Choose and submit task-relevant answers when delegated, including custom and multiple-choice answers in Fusion and Open Fusion.
- Preserve exact prompts when requested and create drafts only on explicit request.
- Protect manual input, track input ownership across clarifications, and prevent uncertain submissions from being replayed.
- Keep result-dependent work waiting for attributable terminal results.

Validation includes 583 automated regression checks, typechecking, isolated Electron/PTY checks, and four live configured-model scenarios using disposable terminal adapters. Physical menus in every installed CLI were not tested; native screen interpretation remains model-dependent.

Use **Check for update**, then **Update** and **Restart** when ready. Publishing this release does not close or restart an active workspace.
