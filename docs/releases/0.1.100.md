# More natural conversations and remembered work

Vibe gives shorter, warmer replies and reports what happened instead of repeating your request or reading internal status labels.

- Answer Vibe's questions and decisions without saying **Hey Vibe** again. The answer window opens automatically, including when wake-word mode is off and local detection is available.
- Dismiss the exchange with **never mind**, **that's all**, **stop listening**, or the microphone's **X**. Terminal work and your voice preferences remain intact.
- Open **Orchestrator → Work history** to see observed completed, failed, and interrupted agent turns. Filter by project or use **All projects**, search results, and ask Vibe **What's been done?** Records remain after terminals close.
- Resume saved conversations more reliably, with a specific title confirmation when speech mishears a name.
- Reduce command-format failures and completion retry loops while preserving input ownership, terminal identity, and protection against duplicate submissions.

Work history records observed agent turn endings and available result excerpts; it does not independently verify task success or reconstruct previously unobserved work. Voice tests use simulated audio; physical microphone behavior has not been verified on every device.

Use **Check for update**, then **Update** and **Restart** when ready. Publishing this release does not interrupt an active workspace.
