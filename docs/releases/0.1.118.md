# Lina Terminal 0.1.118

- Chats now sits directly below Projects. Open an existing conversation in its terminal, search saved chats, rename sidebar entries, archive them, or read saved history in a terminal-style view.
- Chat identity, workspace state and app-owned drafts are saved locally in SQLite. Reopening after an unexpected exit preserves saved conversations for deliberate recovery, while missing native history stays visible instead of silently starting another chat.
- Codex Web can discover and resume its exact saved conversations from its private history store.
- The Orchestrator has a simpler dispatch pipeline, improved command interpretation, persistent task/context memory, clearer responses, and voice endpointing refinements.
- An opt-in local phone bridge adds desktop-approved pairing and read-only terminal/history access. It is off by default.
- Repository work also includes the mobile client, isolated account-server foundation and disconnected account/admin previews. Hosted account deployment and account integration are not enabled by this desktop update.

Native unsent terminal input is not included in Lina's draft recovery guarantee.
Recovery copies contain bounded recent prose and cannot replace a missing
provider's full execution context. See the engineering recovery record for the
remaining hardening work.

Windows updates retain the existing user profile and are applied only through
the explicit Update / Restart controls.
