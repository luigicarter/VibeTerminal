# Lina Terminal 0.1.127

- New terminals start at 520px tall, with their height adjusted to the available space.
- Asking to "open a new Codex terminal" opens Codex. Requests for Open Codex, Codex Web, Open Claude Code and Open Fusion retain their distinct launcher names, including repeated opening verbs in voice transcripts.
- The launcher you name takes precedence over the Orchestrator's planned choice. Codex, Open Codex and Codex Web panes no longer substitute for one another when assigning work.
- When a requested existing provider has no open pane, the Orchestrator asks whether to open one and remembers the provider when you answer "A brand new one."
- New work without a specified launcher can use the project's remembered provider preference. More terminal-status questions are answered directly from the current roster.
- Open Codex displays the provider's own bounded stream-error message when available, making failed requests easier to diagnose. This does not yet make every failed Codex turn settle automatically in the Orchestrator.

Updates apply through Check for update → Update → Restart. Publication does not restart an active workspace.
