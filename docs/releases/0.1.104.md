# Lina Terminal 0.1.104

- Rename the app to Lina Terminal and the wake phrase to **Hey Lina**, preserving existing settings, workspaces, and update compatibility.
- Improve quiet/fast wake recognition and distinguish similar names such as Lisa and Linda without enabling them as wake phrases.
- Fix wheel scrolling through terminal history, including panes with mouse tracking and exited terminals. Shift-wheel can select local history while a running terminal application retains its native wheel controls.
- Improve queued task delivery, free-terminal selection, startup prompt detection, and continuation without replaying uncertain submissions.
- Keep readiness watches waiting while questions or approvals still need input.
- Reject incomplete provider responses before interpreting commands or assigning terminal work.
- Add provider-specific native terminal navigation and capability-aware model options.
- Simplify routine completion messages and add a quiet completion cue for voice commands.

Updates remain user-controlled: choose **Check for update**, then **Update** and **Restart** when ready.
