# Orchestrator navigation and clearer session status

- Ask the Orchestrator to open Settings, History, the dashboard, Multi mode, or an existing project. Running terminals stay active while views change.
- Relay requests recognize more conversational phrasing and project references. A target clarification can complete the immediately preceding unsent request while preserving its exact text and session identity.
- Dashboard bubbles use a staggered layout, clearer status colors, and more accurate runtime and pending-interaction information.
- Spoken replies remove Markdown formatting while keeping the original formatting in chat and history.
- Codex terminals keep a steady caret through default cursor resets. The project sidebar fills the available height and keeps Settings reachable.

Automated checks cover relay policy, speech text, navigation, dashboard behavior, and cursor rendering. Live provider interpretation and real-microphone audio were not exercised.

Use Check for update, then Update and Restart to install.
