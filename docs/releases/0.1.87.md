# Orchestrator visualization and voice fixes

- Added an Orchestrator pane with clear-glass session bubbles, status colors,
  gentle floating, and recency based on user interaction. Sessions addressed by
  Vibe expand together with violet highlighting; other bubbles stay smaller.
- Smooth scaling uses reserved space and stable positions. Narrow/many-session
  views scroll, reduced motion is supported, and existing terminals stay mounted.
- Simplified setup to API key, model and on/off. Saved keys are greyed out with
  Change, and first microphone use asks Allow microphone / Not now.
- Kept Hey Vibe detection local on one CPU thread. The mic appears only inside
  vibeTerminal, while its audio renderer stays hidden and non-focusable.
- Repaired the unavailable speech configuration, misleading rejection audio,
  voice-readiness races and failed-settings-restart cleanup. Runtime errors use
  a brief local chime with stage-specific text.
- Removed the session navigation list and persistent bottom dock. Optional tools
  remain available on demand; automatic activity reports default to off.
- Improved natural command handling and action receipts. Model controls remain
  inside the app; external file/folder opening requires an explicit UI action.

Local checks cover mocked provider transport, real PTYs and the bundled native
wake detector. Physical microphone quality and authenticated live speech remain
separate acceptance checks. Updating remains manual and does not auto-restart
running work.
