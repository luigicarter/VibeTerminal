# Lina Terminal 0.1.120

- Chats is directly below Projects, with terminal-format conversations, exact saved-chat resume, search, rename, archive and a terminal-style history viewer.
- Local SQLite storage preserves committed chat identity, workspace state and app-owned drafts. Startup ownership prevents a late initial save from overwriting an acknowledged newer workspace. Unexpected exits restore agent panes for deliberate recovery, without replaying prompts.
- Codex Web recovers exact conversations from its private native history.
- The Orchestrator includes the dispatch, memory and voice refinements, plus exact-terminal-ID routing repairs.
- The opt-in phone bridge provides desktop-approved pairing and read-only terminal/history access. It remains off by default.
- Chat rows retain usable space in short windows even when provider-history warnings are present.

This release supersedes the unpublished 0.1.118 and 0.1.119 candidates. Repository
source also includes the mobile client, isolated account-server foundation and
disconnected account/admin previews; hosted account deployment and integration
are not enabled by this desktop update.

Native unsent terminal input is outside Lina's app-owned draft recovery.
Bounded history copies cannot replace a provider's full execution context.
Updates preserve the user profile and apply through explicit Update / Restart.
