Terminal resource use and Orchestrator reliability improve in this release.

- Closed terminals release retained buffers, observers and runtime state. Screen observation batches redraws, and terminal output applies backpressure while preserving order and scrollback.
- Terminal activity updates no longer copy unchanged conversation history, reducing work in long conversations and larger workspaces.
- Conditional terminal closure checks current activity and input state. Reads reject changed conversation identities, and workspace summaries include background activity and current questions.
- The Orchestrator can discover supported configuration and capability facts. Model readiness uses the same planning schema as real requests.

Free-form model answers and native child approval matching still have the limitations described in the capability audit. The repair roadmap includes further work; this release ships the implemented fixes only.

Install through **Check for update → Update → Restart**. Publication does not restart active workspaces.
