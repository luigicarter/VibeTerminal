# Lina Terminal 0.1.121

- Chats is directly below Projects, with terminal-format conversations, exact saved-chat resume, search, rename, archive and a terminal-style history viewer.
- Local SQLite storage preserves committed chat identity, workspace state and app-owned drafts. Startup ownership protects acknowledged changes from late initial saves, and unexpected exits restore agent panes for deliberate recovery without replaying prompts.
- Codex Web uses its private native history for exact conversation recovery.
- The Orchestrator includes dispatch, memory and voice refinements and exact-terminal-ID routing repairs. Brief Windows file locks now receive bounded atomic-save retries, preserving the last committed file on permanent failure.
- Chat rows retain usable space in short windows when provider-history warnings appear.
- The opt-in phone bridge provides desktop-approved pairing and read-only terminal/history access. It remains off by default.

Repository source also includes the mobile client, isolated account-server
foundation and disconnected account/admin previews. Hosted account deployment,
account integration and mobile store submission remain separate work.

This supersedes the unpublished 0.1.118–0.1.120 candidates. Native unsent terminal
input is outside Lina's app-owned draft recovery; bounded history copies cannot
replace a provider's full execution context. Updates preserve the user profile
and apply through explicit Update / Restart.
