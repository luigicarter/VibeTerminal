# Lina Terminal 0.1.119

- Chats sits directly below Projects, with terminal-format conversations, exact saved-chat resume, search, rename, archive and a terminal-style history viewer.
- Local SQLite storage preserves committed chat identity, workspace state and app-owned drafts. Unexpected exits restore saved agent panes for deliberate recovery, without replaying old prompts.
- Codex Web uses its private native history for exact conversation recovery.
- The Orchestrator gains the dispatch, memory and voice refinements, plus a repair for requests addressed to an exact terminal ID.
- The opt-in phone bridge adds desktop-approved pairing and read-only terminal/history access. It remains off by default.
- Repository source includes the mobile client, isolated account-server foundation and disconnected account/admin previews. Hosted account deployment and client integration remain separate.

This supersedes the unpublished 0.1.118 candidate. Release verification was
updated for durable workspace startup, and the mobile mock now owns its terminal
preview dependencies so its checks work in a clean installation.

Native unsent terminal input is outside Lina's app-owned draft recovery.
Bounded history copies cannot replace a provider's full execution context.
Updates preserve the user profile and apply through the explicit Update /
Restart controls.
