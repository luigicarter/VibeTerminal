- Keep project and terminal context attached to each task, including follow-ups and clarification answers.
- Wait for observed review results before starting dependent fixes.
- Answer Orchestrator questions by voice without repeating the wake phrase.
- Restore recent conversation history locally, with unfinished tasks paused after restart.
- Preserve unfinished work after errors and avoid replaying actions already sent.
- Handle model context limits while protecting the current instruction, terminal identity and complete session counts.
