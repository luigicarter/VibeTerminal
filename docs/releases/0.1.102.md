# vibeTerminal 0.1.102

- Let Orchestrator assign work to a related conversation or create a new worker, while keeping follow-ups attached to their original task.
- Add Grok Build launching, native session discovery, conversation history, and status hooks.
- Improve provider status, background-agent tracking, readiness watches, and task-result dependencies without treating unverified activity as completed work.
- Restore current conversations more reliably after reopening the app, while keeping paused panes paused.
- Fix Fusion and Open Fusion startup, remount, model-change, resume, and clean-exit recovery races.
- Strengthen prompt delivery, cancellation, and conversation identity checks to prevent stale actions and duplicate submissions.
- Improve voice wake interruption and push-to-talk, release cancelled speech promptly, and prevent old error audio from overlapping later replies.
- Show project names more clearly in the dashboard and keep live approval indicators consistent.
- Harden native history discovery against incomplete, conflicting, or malformed session metadata.

Updates remain user-controlled: choose **Check for update**, then **Update** and **Restart** when ready.
