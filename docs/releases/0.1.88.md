# Spoken replies and missed-speech feedback

- Fixed spoken replies by requesting the supported PCM format and reading the
  response's sample rate and channel metadata correctly.
- Preserved short commands spoken before Hey Vibe detection finishes, so they
  reach transcription instead of being discarded as silence.
- Added spoken retry feedback when speech is missed or transcription is empty.
  Empty answers to agent questions repeat the question without guessing an answer.
- Added offline spoken explanations for service failures, busy requests, spending
  limits and rejected answers. These work without another cloud speech request.

Verified with 289 backend tests, the production build and an isolated Electron
voice flow using scripted microphone input and provider responses. Physical
microphone quality and authenticated live speech remain unverified.

Use Check for update, then Update and Restart to install. Running work is not
automatically restarted.
